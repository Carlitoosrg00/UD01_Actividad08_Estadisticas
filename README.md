📊 UD01_Actividad08_Estadisticas
Descripción

Proyecto desarrollado en Kotlin que permite generar o introducir 100 números y realizar cálculos estadísticos básicos de forma rápida y sencilla.

✨ Funcionalidades
Generación de 100 números aleatorios.
Introducción manual de datos.
Visualización de los números almacenados.
Cálculo de la media.
Cálculo de la moda.
Cálculo de la desviación típica.
Consulta de todas las estadísticas desde un menú interactivo.
🛠 Tecnologías utilizadas
Kotlin
IntelliJ IDEA
Librería estándar de Kotlin
🎯 Objetivo

Aplicar los conceptos fundamentales de programación mediante el uso de listas, funciones, estructuras de control y operaciones matemáticas para el análisis de datos.
